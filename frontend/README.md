The active gaming web application for **AmratGames.com**, built with React 18, Vite, Ant Design, and Tailwind CSS v4.

---

## 🎮 Included Originals

- **Crash**: Real-time curve with exponential multiplier and auto-cashout.
- **Plinko**: Physics pegboard with 8–16 rows, Low/Medium/High volatility, and special ball tiers.
- **Mines**: 5×5 diamond minefield with configurable 1–24 mines and instant cashout.
- **Dino Run**: Endless arcade runner with obstacle jumping and increasing survival multipliers.

---

## 🇮🇳 Indian Player Features

- **No Dollars ($)**: Zero dollar signs or USD fees. 100% direct INR and crypto.
- **Supported Currencies**: Indian Rupee (`₹ INR`), Bitcoin (`₿ BTC`), and Tether (`₮ USDT`).
- **Payment Methods**: Direct UPI (Google Pay, PhonePe, Paytm, BHIM), NetBanking, and IMPS.
- **Practice Balance**: Free ₹10,000.00 refillable virtual wallet.

## 🚀 Deployment (Vercel)

This frontend contains `vercel.json` configured for Single Page Application (SPA) rewrites.

```bash
# Build locally
pnpm run build

# Preview build
pnpm run preview
```
