# amratgames.com Backend Engine

Workbench, Telemetry & GraphQL Engine for AmratGames.com, built with TanStack Start, React and Tailwind CSS v4.

## Develop

```bash
pnpm install
pnpm dev          # http://localhost:3001
```

## Structure

- `src/routes/`: backend API Explorer, GraphQL telemetry, and developer documentation.
- `src/styles.css`: Royal gold design tokens and custom CSS pieces.
